Hello Affineurs,

It's day 2 of the Roguefort Early Access and it's also... my birthday! But there's no time to waste as I've been up all night working hard.

This is an update that specifically addresses player feedback, and I hope that it helps improve the player experience on a number of fronts. A few headlines here and then all the detail below.

First up, thanks to community member zawmbie for the 2.5D analysis and to Vitowns and everyone who reported the issues with 2.5D and 3D. The fixes are in and I hope they will help boost performance on the 2.5D view mode especially, for that Diablo-esque feeling.

Thanks also a number of people who reported the Linux startup and rendering issues. Hopefully there will be some improvements on that front too, and I will continue to work tirelessly until it runs perfectly on all distributions and, ideally, devices/rigs.

I've also done some improvements/fixes to co-op and the big news (you heard it here first) is that I'm currently wiring up the ability to host your own servers, while also looking to get dedicated online servers set up. So the co-op play will be running smoothly very soon and thanks for your patience.

The last highlight is around gendered pronouns in the game. A few community members expressed that they weren't so keen on pronouns being shown in the game, as it felt ideological. I said this in the forums, but I'll say it again, this game is 100% about player freedom of choice and customisation. The whole reason pronouns are in the game was because during playtesting, the *lack* of them meant that players couldn't make informed choices about how they interacted with NPCs (e.g., getting married to an NPC and raising a family). So pronouns were introduced because that seemed like a pretty reasonable thing in a game with a social simulation this complex. A consequence of this is that every NPC thereby had their pronoun displayed, and yes it is quite visible, but it is intentionally that way so that players can be free to interact with NPCs however they would like, without the game telling you what you should do or making you guess. So, I've added a new setting, which enables pronouns to be turned off when interacting with NPCs. Dialogue isn't changed - if you are interacting with a woman, it's not going to stop saying "She wants to do X" or whatever. But it also won't be putting pronouns up front and center every time, if that's how you'd prefer it.

Thanks again for playing and for being part of this rapidly growing community - see you in The Old Mouth for a pint or two.

Tim

2.5D performance3

  • Walking through a town in 2.5D should stutter far less. Community member zawmbie did a super job with the analysis and found the two main causes, which if you really wanna know is that every new animation frame for a townsperson re-sent a whole page of sprite art to the graphics card, and every figure's pose was worked out again on every frame. Both are fixed.zawmbieVitowns
  • While I was in there I found two more things. Each step past a house rebuilt the faded doors and windows from scratch, and every roof in view was rebuilt on every step through a town. Roofs now only rebuild when that building changes, in 2.5D and first person.
  • Nothing looks different. Every one of these changes draws exactly the same picture as before.

Linux3

  • The game should now start and draw properly on Wayland desktops. It was running as a native Wayland window, where the graphics path failed in three different ways: the game not starting, a black 2D view, or a window that never appeared. It now runs through XWayland when it can.MagicBurritoColorYakChryseusCrassius Curiospli.twachtelhorst
  • If you prefer native Wayland, launching with ROGUEFORT_NATIVE_WAYLAND=1 brings it back.
  • The game's log now says which window system it ran under and what your sound server reports for the game, which will help me with the reports of no sound on Linux.juh9870

In the meantime, you can add --no-steam-overlay to the game's launch options in Steam, which keeps Alt+Tab clean for some players.
